🔧 DTCar Clone — leitura de módulos

1 · Adaptador OBD

Procurando adaptadores pareados…
Este app só lê. Ele nunca apaga falha, grava ou regrava módulo — isso é barrado no próprio app, não dá para um site mandar.

2 · Carro e condição da leitura

Rápido: OBD padrão + faixas conhecidas de cada módulo. Alguns minutos.
Completo: varre todos os identificadores de cada módulo. Mais de 1 hora por módulo — carro no carregador de bateria.
O clone também mapeia as saídas (ventoinha, relés…) mandando o pedido incompleto, que o módulo só pode recusar. Mesmo assim, faça o primeiro mapeamento num carro seu ou módulo de bancada, motor desligado — nem todo módulo confere o pedido do mesmo jeito.
